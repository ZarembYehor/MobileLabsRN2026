# Лабораторна робота №4: Робота з файловою системою в React Native з використанням бібліотеки expo-file-system

## Мета
Опанувати механізми роботи з локальною файловою системою мобільного пристрою, використовуючи можливості бібліотеки expo- file-system. Закріпити навички реалізації базових операцій над файлами й папками, організації файлової навігації та аналізу стану файлової системи.

## Основні можливості

### 1. Навігація та перегляд файлів
- **Головний екран (HomeScreen)** – відображає статистику сховища (загальний, вільний, зайнятий обсяг) та кнопку для переходу до файлового менеджера.
- **Файловий менеджер (FileManagerScreen)** – список вмісту обраної папки з можливістю навігації:
  - Перехід у підпапки (натискання на назву папки).
  - Відкриття текстового файлу в редакторі (натискання на файл).
  - Перегляд інформації про файл/папку (довге натискання).
  - Видалення файлів або папок (натискання на іконку кошика).

### 2. Робота з файлами та папками
- **Створення нових об'єктів**:
  - Папка – створюється порожня директорія.
  - Текстовий файл – при створенні можна вказати початковий вміст (необов'язково). Якщо поле залишити порожнім, файл створиться пустим.
- **Видалення** – підтвердження дії через діалогове вікно.

### 3. Редактор файлів (FileEditorScreen)
- Відкриття текстового файлу для читання/редагування.
- Багаторядкове поле введення з можливістю зміни вмісту.
- Кнопка «Зберегти зміни» – оновлює файл на диску та повертає до попереднього екрана.
- Обробка помилок читання/запису з відображенням діалогів.

### 4. Детальна інформація про файл (FileInfoScreen)
Відображаються наступні атрибути:
- **Назва файлу** – ім'я з розширенням.
- **Тип файлу** – визначається на основі розширення (наприклад: "Текстовий файл (.txt)", "Зображення JPEG", "PDF документ" тощо). Для папок – "Папка".
- **Розмір** (лише для файлів) – відформатовано у байтах, кілобайтах тощо.
- **Дата останньої модифікації** – локальний формат дати та часу.

### 5. Статистика пам'яті
На головному екрані виводяться:
- Загальний обсяг внутрішньої пам'яті.
- Вільний простір.
- Зайнятий простір (різниця між загальним та вільним).
Значення отримуються за допомогою **нового** та **legacy** API `expo-file-system` для уникнення депрекейшн-попереджень.

### 6. Користувацький досвід
- **Підсвічування типів** – папки виділяються синім кольором, файли – чорним.
- **Іконки** – 📁 для папок, 📄 для файлів.
- **Підтвердження дій** – Alert перед видаленням, сповіщення про успішне збереження або помилку.
- **Адаптивна клавіатура** – на екрані редактора використовується `KeyboardAvoidingView`.

## Інструкція із запуску

1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/ZarembYehor/MobileLabsRN2026.git
2. **Перейдіть до папки проєкту**
   ```bash
   cd MobileLabsRN2026/lab4
3. **Встановіть необхідні залежності:**
   ```bash
   npm install
4. **Запустіть Expo CLI:**
   ```bash
   npx expo start
5. **Відкрийте додаток:**
   * Скануйте QR-код через додаток Expo Go на вашому смартфоні.
   * Або натисніть **a** для запуску на Android Emulator.
   * Або натисніть **i** для запуску на iOS Simulator.
